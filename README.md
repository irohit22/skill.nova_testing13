## 🌟 Overview

**SkillNova AI** is a production-quality, interactive AI-powered learning and career intelligence platform designed for students and ambitious professionals. Rather than treating learners like passive consumers of video catalogs, SkillNova AI uses first-principles cognitive science:
1. **Deconstructs what you already know** vs high-leverage blind spots.
2. **Synthesizes two distinct learning pathways**: **The Smart Route** (rapid time efficiency) vs **The Deep Mastery Route** (unfair advantage, real projects, Socratic rigor).
3. **Validates real competence** through timed, diagnostic mock examinations and radar gap analysis.
4. **Scans The Future Signal**: Identifies which workflow tasks are automated by AI versus irreplaceable human superpowers (judgment, empathy, systems architecture).

## 🚀 Quick Start & Launch

### Prerequisites
- **Node.js** (v20+ or v22+ LTS recommended)
- **npm** (v10+)

### 1. Installation
Clone or navigate to the repository and install all dependencies:
```bash
npm install
```

### 2. Configure Environment (Optional)
Copy the example environment configuration:
```bash
cp .env.example .env
```

To enable live Google Gemini AI generative analysis and question formulation, add your API key to `.env`:
```env
PORT=3001
GEMINI_API_KEY=your_gemini_api_key_here
```
> **Note on Demo Mode**: If no API key is provided, SkillNova AI automatically launches its built-in **High-Fidelity Offline Educational Core**. The app remains 100% interactive with rich authentic domain intelligence, questions, keyword mnemonics, and roadmaps without failing or crashing.

### 3. Launch Full-Stack Application
Start both the Express backend API and the Vite React frontend concurrently:
```bash
npm run dev
```

- **Frontend Application**: [http://localhost:5173](http://localhost:5173)
- **Backend API Server**: [http://localhost:3001](http://localhost:3001)

### 4. Production Build & Run
To compile the production bundle and serve statically:
```bash
npm run build
npm start
```

## 🌌 Core Features Implemented

### 1. Signature Cinematic Visual Identity & Knowledge Reactor
- **Deep space dark theme** with midnight navy (`#040711`), electric cyan (`#00f0ff`), luminous aqua (`#22d3ee`), and acid-lime accents (`#ccff00`).
- **Interactive Knowledge Reactor**: A central glowing cybernetic core connected to floating knowledge nodes (Attention Mechanics, Vector Space, Active Recall, Idempotence, Benchmarks, Future Signals). Hovering or selecting nodes activates orbital beams and real-time HUD telemetry.
- **Ambient WebGL/Canvas Particle Field** and cybernetic grid patterns.
- **Synthesizer Web Audio Feedback**: Tactile cybernetic clicks, arpeggio success chimes, and level-up cues via the native Web Audio API (with instant mute toggle).

### 2. 4-Step Personalized Knowledge Onboarding
- **Goal Configuration**: Select from 8 specialized domains (Generative AI & ML, Programming & CS, Competitive Exams, College Subjects, Interviews & Career, Future-of-Work, Creative, or Custom).
- **Knowledge Frontier Profiling**: Free-text description + self-assessed level (Beginner, Intermediate, Advanced).
- **Constraints & Strategy Selection**: Daily time commitment (30m to 4h+), target window/deadline, and pathway preference.
- **Animated AI Synthesis**: Multi-phase scanning feedback showing curriculum benchmarking, first-principles deconstruction, and roadmap compilation.

### 3. AI Knowledge Analyzer Report
- **Current Estimated Knowledge Level**: Clearly labeled as an initial estimate until verified by diagnostic quiz.
- **Known Concepts vs High-Leverage Blind Spots**: Two-column contrast identifying exact conceptual frontiers.
- **Priority Topics Ranked by Learning ROI**: High-yield topics with estimated study hours.
- **Common Misconceptions & Traps**: Deconstructs why specific concepts confuse learners and provides the real underlying principle.
- **Interactive Keyword Glossary**: Plain-language definitions, concrete engineering examples, memory tricks/mnemonics, and mastery checkboxes (+25 XP each).

### 4. Dual Personalized Pathways (Side-by-Side Comparison)
- **Path A — The Smart Route** (*"Learn efficiently"*): Practical 80/20 approach, high-yield summaries, active recall drills, memory checklists, and short daily sessions.
- **Path B — The Deep Mastery Route** (*"Build an unfair advantage"*): Rigorous first-principles proofs, challenging edge cases, real portfolio projects, Feynman technique sessions, and error post-mortems.
- **Dynamic Switcher**: One-click selection recalculates study milestones and updates the Mission Dashboard.

### 5. Personalized AI Study Plan & Roadmap
- **Dynamic Task Roadmap**: Daily tasks labeled by category (Theory, Practice, Active Recall, Mock Test, Project) and priority (CRITICAL, HIGH, MEDIUM).
- **Weekly Milestones**: Clear deliverables and goal descriptions.
- **Interactive Task Completion**: Instant checkbox updates, XP rewards (+60 XP), and real-time recalculation of remaining study hours.
- **Custom Task Builder**: Add your own tasks directly into the roadmap.
- **Filtering**: Filter tasks by status (All, Pending, Completed) or category.

### 6. AI Mock Test Lab & Gap Analysis
- **Configurable Diagnostic Exam**: Choose topic, difficulty (Foundational, Intermediate, Advanced, Mastery), question count, question type (multiple choice, short answer, mixed), and timer.
- **Live Test Runner**: Question navigator palette, flag question for review, countdown clock with warning pulses, and instant or end-of-test explanation reveals.
- **Test Results & Knowledge Gap Screen**:
  - Score summary, percentage, time spent, and performance grade.
  - Topic-wise proficiency bar chart powered by Recharts.
  - **Diagnostic Verification Update**: Updates the learner's verified score and level on their active mission profile.
  - **Remedial Task Injector**: Automatically identifies topics where score was < 70% and generates targeted practice tasks directly into the Study Plan.

### 7. The Future Signal (Future-of-Work Intelligence)
- **AI Automation Matrix**: Pinpoints routine tasks automated by AI versus irreplaceable human superpowers (strategic judgment, ethical boundary design, systems thinking, empathy).
- **Career Roles & Salary Ranges**: High-growth roles with verified compensation data and transparent source citations.
- **Interactive "Imagine Your Future" Simulator**: Step through progressive capability tiers from Foundation to Strategic Lead with signature project deliverables.
- **Portfolio Project Briefs**: Specification briefs with deliverables for resume-worthy capstones.

### 8. AI Study Companion (Socratic Tutor)
- **Context-Aware Dialogue**: Knows your active topic, current level, and selected learning pathway.
- **Socratic Pedagogy**: Teaches through reasoning and analogies rather than dumping raw answers.
- **Quick Prompt Chips**: Beginner explanations, real-world examples, diagnostic challenges, and flashcards.
- **Interaction Tools**: Copy markdown, reset dialogue, and instant message history.

### 9. Gamification & Engagement Engine
- **Fair XP Progression**: Earned strictly for completed tasks, mock tests, and keyword mastery.
- **Level Tiers**: Nova Initiate (Lvl 1) → Knowledge Seeker (Lvl 2) → Orbital Scholar (Lvl 3) → Quantum Practitioner (Lvl 4) → Master Architect (Lvl 5+).
- **Daily Streak Counter**: Streak tracking to maintain learning consistency.
- **Cognitive Badges**: "First Light", "Diagnostic Certified", "Deep Diver", "Flawless Test", "Speed Demon", and "Architect of Tomorrow".
- **Mastery Radar Chart**: Visual constellation of topic strengths.

### 10. Settings & Privacy
- Local storage data backup (JSON export).
- Default sample mission loader.
- Full factory reset capability.
- Sound FX toggle.

## 🔒 Security & AI Transparency

1. **Zero Frontend Key Exposure**: API keys are strictly loaded on the Express server (`.env`) and never exposed in frontend browser bundles or client requests.
2. **Honest System Status**: The app always displays an honest status badge (e.g., `GEMINI LIVE` vs `DEMO CORE`). It never fabricates an active AI request when running offline.
3. **No Employment Guarantees**: Salary and demand figures reference published industry indices (WEF Future of Jobs, Levels.fyi aggregate) and are explicitly labeled as market estimates.

## ⚖️ Honest Limitations

- **Diagnostic Scope**: While diagnostic quizzes evaluate conceptual understanding and error patterns, full professional certification in regulated disciplines requires formal accredited examinations.
- **Offline Mode vs Live AI**: In demo/offline mode, topics outside the primary knowledge packs utilize generalized first-principles frameworks. Configuring a Google Gemini API key unlocks unlimited generative analysis on niche domains.
